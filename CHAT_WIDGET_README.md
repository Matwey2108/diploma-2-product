# Виджет чата поддержки клиентов

Современный, чистый и профессиональный виджет чата для веб-сайтов.

## Особенности

### Основные компоненты

1. **ChatWidget** - Главный компонент виджета
   - Управляет состоянием (закрыт/минимизирован/открыт)
   - Координирует работу всех дочерних компонентов

2. **ChatButton** - Плавающая кнопка чата
   - Круглая синяя кнопка с текстом "Чат с поддержкой"
   - Анимированный индикатор онлайн-статуса
   - Пульсирующая анимация для привлечения внимания

3. **ChatWindow** - Окно чата (380×620 px)
   - Адаптивный дизайн (полный экран на мобильных)
   - Форма приветствия при первом открытии
   - Плавные анимации открытия/закрытия

4. **ChatHeader** - Шапка чата
   - Логотип и название "Поддержка"
   - Индикатор онлайн-статуса
   - Кнопки минимизации и закрытия

5. **ChatMessages** - Область сообщений
   - Автоматическая прокрутка к новым сообщениям
   - Поддержка различных типов сообщений
   - Плавные анимации появления

6. **ChatMessage** - Компонент сообщения
   - Разные стили для пользователя и бота
   - Временные метки
   - Статусы доставки (отправка/отправлено/доставлено/прочитано)

7. **ChatInput** - Поле ввода
   - Плейсхолдер "Напишите сообщение..."
   - Кнопки вложений и эмодзи
   - Кнопка отправки с анимацией

8. **WelcomeForm** - Форма начала чата
   - Поля: имя, email, тема
   - Валидация обязательных полей
   - Современный дизайн с иконками

9. **QuickReplies** - Быстрые ответы
   - Чипсы с предложенными вопросами
   - Анимация при наведении
   - Автоматическая отправка при клике

10. **TypingIndicator** - Индикатор набора текста
    - Три анимированные точки
    - Плавная пульсация

11. **MinimizedChat** - Минимизированное состояние
    - Компактная панель внизу экрана
    - Счетчик непрочитанных сообщений
    - Быстрое развертывание

12. **SystemMessage** - Системные сообщения
    - Уведомления о событиях чата
    - Центрированное отображение

## Цветовая палитра

- **Основной цвет**: #0066FF (синий)
- **Hover**: #0052CC
- **Светлый фон**: #E6F0FF
- **Онлайн**: #10B981 (зеленый)
- **Нейтральные**: оттенки серого (#F9FAFB - #111827)

## Типографика

- **Шрифт**: Inter (400, 500, 600, 700)
- **Заголовки**: 18-24px, semibold
- **Основной текст**: 14px, regular
- **Подписи**: 12px, regular
- **Кнопки**: 14px, medium

## Адаптивность

### Десктоп (>768px)
- Фиксированный размер: 380×620 px
- Скругленные углы: 16px
- Позиция: правый нижний угол (24px от краев)

### Мобильные (<768px)
- Полноэкранный режим
- Без скругления углов
- Позиция: от края до края

## Состояния

### Виджет
1. **Закрыт** - показана только плавающая кнопка
2. **Минимизирован** - компактная панель с онлайн-статусом
3. **Открыт** - полное окно чата

### Сообщения
1. **Отправка** - спиннер загрузки
2. **Отправлено** - одна галочка
3. **Доставлено** - две галочки (серые)
4. **Прочитано** - две галочки (синие)

## Использование

```tsx
import { ChatWidget } from "./components/ChatWidget";

function App() {
  return (
    <>
      {/* Ваш контент */}
      <ChatWidget />
    </>
  );
}
```

## Настройка

### Изменение цветов
Отредактируйте CSS-переменные в `/src/styles/theme.css`:

```css
--chat-primary: #0066FF;
--chat-primary-hover: #0052CC;
--chat-green: #10B981;
```

### Изменение размеров
Отредактируйте классы в `ChatWindow.tsx`:

```tsx
className="... w-[380px] h-[620px] ..."
```

### Изменение текста
Все тексты находятся в компонентах:
- Приветственные сообщения: `ChatWindow.tsx`
- Быстрые ответы: `ChatWindow.tsx`
- Заголовки: `ChatHeader.tsx`

## Анимации

Все анимации реализованы с помощью библиотеки Motion (Framer Motion):
- Плавное появление/исчезновение
- Масштабирование при открытии
- Пульсация индикаторов
- Анимация набора текста

## Доступность

- Семантическая HTML-разметка
- Aria-labels для интерактивных элементов
- Поддержка клавиатурной навигации
- Контрастные цвета (WCAG AA)

## Производительность

- Оптимизированные анимации (GPU-ускорение)
- Ленивая загрузка сообщений
- Debounce для ввода текста
- Минимальный bundle size

## Браузерная поддержка

- Chrome 90+
- Firefox 88+

- Edge 90+
